# Система управления обучением

## Описание проекта

Проект создан для образовательной платформы, разработанной с использованием Django и Django REST Framework.
Позволяет управлять курсами, уроками, платежами, подписками и пользователями.
Поддерживает фильтрацию, сортировку и вывод связанных данных.

1. Настройка проекта
   Создан Django-проект с приложениями: materials, users
   Подключены сторонние пакеты:
   Django REST Framework
   django-filter — для расширенной фильтрации данных
   Настроена обработка медиафайлов для загрузки изображений и аватаров
   Настроена база данных PostgreSQL
   Создана автодокументация API с использованием DRF-YASG
   Использована библиотека stripe для работы с платежами

### 2. Приложения и модели

###### Приложение users -

реализована кастомная модель пользователя, наследованная от AbstractUser.
Аутентификация осуществляется по электронной почте. Реализована отложенная задача
для проверки периода не активности пользователей и их блокировки.

Дополнительные поля профиля:

* Номер телефона
* Город проживания
* Аватар

Содержит модели для работы с платежами Payments и подписками Subscription.

###### Приложение materials -

Содержит две основные модели: курс и урок. Реализована
периодическая задача для отправки уведомлений о новых обновлениях курсов пользователям.

#### Модель Course (Курс)

* name Название курса
* image Изображение-превью курса
* description Подробное описание курса

#### Модель Lesson (Урок)

* name Название урока
* image Изображение-превью урока
* description Описание урока
* link Ссылка на видеоурок
* course Связь с курсом (внешний ключ, один ко многим)

### 3. Реализация CRUD

* Курсы -
  использован ModelViewSet для реализации всех операций: создание, просмотр, редактирование, удаление
  Эндпоинт: /courses/
* Уроки -
  реализованы через generic-классы: LessonCreateListRetrieveUpdateDestroyAPIView
  Полная поддержка всех CRUD-операций
  Эндпоинт: /lessons/

### 4. Фильтрация и сортировка

Фильтрация и сортировка по:

* курсу
* уроку
* платежам
* подпискам

Функциональность реализована с помощью DjangoFilterBackend и FilterSet.

### 5. Тестирование

- Все эндпоинты протестированы с использованием Postman
- Проверена корректность работы CRUD-операций

### 7. Установка проекта

Установка с использованием Poetry (рекомендуется)

- git clone https://github.com/PavelOleynikov/DRF.git
- cd DjangoDRF
- poetry install
- poetry shell
- python manage.py migrate
- python manage.py createsuperuser
- python manage.py runserver

* API будет доступно по адресу: http://localhost:8000/
* Для авторизации используйте полученный при регистрации email и пароль
