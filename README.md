# Система управления обучением

## Описание проекта

Проект создан для образовательной платформы, разработанной с использованием Django и Django REST Framework.
Позволяет управлять курсами, уроками, платежами, подписками и пользователями.
Поддерживает фильтрацию, сортировку и вывод связанных данных.

1. Настройка проекта
   Создан Django-проект с приложениями: materials, users
   Подключены сторонние пакеты:
   Django REST Framework
   django-filter — для расширенной фильтрации данных
   Настроена обработка медиафайлов для загрузки изображений и аватаров
   Настроена база данных PostgreSQL
   Создана автодокументация API с использованием DRF-YASG
   Использована библиотека stripe для работы с платежами

### 2. Приложения и модели

###### Приложение users -

реализована кастомная модель пользователя, наследованная от AbstractUser.
Аутентификация осуществляется по электронной почте. Реализована периодическая задача
для проверки периода не активности пользователей и их блокировки.

Дополнительные поля профиля:

* Номер телефона
* Город проживания
* Аватар

Содержит модели для работы с платежами Payments и подписками Subscription.

###### Приложение materials -

Содержит две основные модели: курс и урок. Реализована
отложенная задача для отправки уведомлений о новых обновлениях курсов пользователям.

#### Модель Course (Курс)

* name Название курса
* image Изображение-превью курса
* description Подробное описание курса

#### Модель Lesson (Урок)

* name Название урока
* image Изображение-превью урока
* description Описание урока
* link Ссылка на видеоурок
* course Связь с курсом (внешний ключ, один ко многим)

### 3. Реализация CRUD

* Курсы -
  использован ModelViewSet для реализации всех операций: создание, просмотр, редактирование, удаление
  Эндпоинт: /courses/
* Уроки -
  реализованы через generic-классы: LessonCreateListRetrieveUpdateDestroyAPIView
  Полная поддержка всех CRUD-операций
  Эндпоинт: /lessons/

### 4. Фильтрация и сортировка

Фильтрация и сортировка по:

* курсу
* уроку
* платежам
* подпискам

Функциональность реализована с помощью DjangoFilterBackend и FilterSet.

### 7. Установка проекта

Установка с использованием Poetry (рекомендуется)

- git clone https://github.com/PavelOleynikov/DRF.git
- cd DjangoDRF
- poetry install
- poetry shell
- python manage.py migrate
- python manage.py createsuperuser
- python manage.py runserver

### 8. Запуск проекта с использованием Docker Compose

Файл docker-compose.yml определяет конфигурацию для запуска всех необходимых сервисов вашего проекта: веб-приложения
Django, базы данных PostgreSQL, Redis и Celery (worker и beat).

Предварительные требования:

- Docker установлен и работает.
- Docker Compose установлен (обычно входит в состав Docker Desktop).
- Файл .env с необходимыми переменными окружения (например, DATABASE_NAME, DATABASE_USER, DATABASE_PASSWORD).

Процесс запуска

- сборка и запуск всех сервисов -
  перейдите в корневую директорию вашего проекта (где находится файл docker-compose.yml и Dockerfile).

- Затем выполните следующую команду:
  docker-compose up --build или docker-compose -f docker-compose.yaml up

* API будет доступно по адресу: http://localhost:8000/
* Для авторизации используйте полученный при регистрации email и пароль
* Для доступа к админке используйте адрес: http://localhost:8000/admin/

Проверка сервисов

- docker-compose ps — все контейнеры должны быть в статусе Up
- docker-compose logs -f web — логи Django
- docker-compose logs -f celery — логи Celery

Команды

- Остановка: docker-compose down и удаление контейнеров
- Перезапуск: docker-compose restart
- Миграции: docker-compose exec web python manage.py migrate
- Суперпользователь: docker-compose exec web python manage.py createsuperuser
